术语以仓库 [CONTEXT.md](https://github.com/KeroroC/zija/blob/main/CONTEXT.md) 为准。以下是面向使用的摘要。

## 库存核心

| 概念 | 含义 |
|---|---|
| **物品（Item）** | 描述一种家庭用品「是什么」的资料，可复用（耐用品或消耗品） |
| **批次（Lot）** | 某次购入或某件独立资产；同一物品可有多个批次，各自到期与库存 |
| **库存位（Stock Position）** | 某批次在某位置的当前数量，不得为负 |
| **流水（Movement）** | 库存数量的一次**不可变**变更，是事实来源 |

流水类型：入库 / 领用 / 报损 / 盘点调整 / 移位 / 冲正。

报表侧的「库存变化」不是独立概念，而是同一套流水的筛选视图。

## 附件

- 挂载点：家庭、物品或批次之一，任一时刻恰好一处；可**改挂**而不必重传
- 删除进入**回收站**，保留期内可恢复；也可**永久删除**
- 物品可指定合格图片附件为**封面**（列表缩略图 / 详情头图）

## 提醒

**提醒任务**由规则与库存 reconcile 产生，例如批次临期（EXPIRY）或物品低库存（LOW_STOCK）。状态含待处理、已延后、已完成、已忽略等。

## 报表与导出

- 报表读自己的投影读模型，不直接改库存
- **导出**为 CSV，用于数据携带，不是完整备份
- **全局搜索**：跨物品名 / 品牌 / 标签 / 批次号 / 序列号 / 位置名的中文子串匹配

## 文件完整性

Owner 可调用 `GET /api/v1/files/integrity-report` 查看文件完整性报告。
